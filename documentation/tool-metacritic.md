# Metacritic web parser tool

Since IMDB does not like terminal clients, Metacritic it is for now.

There is no search for now.
Search manuall and then copy the part after `movie/` from the URL and use this for the data fetch.

Which fields are available for you to select, are configured in the `config.metacritic.php` file to make it
easier since not every field the tool provides are needed.
Follow the comments in the file for more details.

An option to make the target fields automatically selected by default to given values is also available
in the config file.

# Setup

Rename the `config-metacritic.php.default` to `config-metacritic.php` in the config folder.
Follow the comments to update the settings. Add the tool to your collection.
